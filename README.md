# CareerPilot AI

AI-powered Career Platform built using React + FastAPI.

## Features
- AI Resume Builder
- ATS Resume Analyzer
- Resume Parser
- Job Search
- Saved Jobs
- Dashboard
- JWT Authentication
- Profile Management
- Notifications

## Tech Stack
Frontend:
- React
- Vite
- Axios
- Tailwind CSS

Backend:
- FastAPI
- SQLAlchemy
- SQLite
- JWT
- Groq API

## Installation

Backend
pip install -r requirements.txt
python run.py

Frontend
npm install
npm run dev
